Dependency inversion in Health

Module view — Health authorization

What we learned

The PostgreSQL suite caught what policy unit tests could not: JDBC could not bind a Java Instant to a timestamp. Converting at the JDBC boundary fixed it without touching the domain. Dependency inversion keeps policy rules testable without Spring or PostgreSQL; the integrated slice checks the wiring.
